# Contributing

Thank you for your interest in contributing to this project.

## Getting Started

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes and keep them focused.
4. Test your changes locally.
5. Commit with a clear, descriptive message.
6. Open a pull request against `main` and explain what changed.

## Code Quality

- Follow the existing project structure and coding conventions.
- Keep changes focused and avoid unrelated modifications.
- Do not commit secrets, credentials, API keys, `.env` files, generated artifacts, or personal data.
- Update documentation when your changes affect setup, behavior, or APIs.

## Pull Requests

Please include:

- A concise summary of the change.
- Relevant testing performed.
- Any configuration or migration steps required.
- Screenshots or recordings when a UI change needs visual context.

## Issues

Before opening an issue, check whether a similar issue already exists. Provide enough detail to reproduce bugs, including relevant error messages and environment information.
